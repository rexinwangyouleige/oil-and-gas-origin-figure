# 选图规则（油气工程 / 油气化学 / 油气能源）

**先回答"这张图要让读者相信什么"，再选图。** 同一批数据，论点不同，图就不同。
推荐图型时给出：首选 + 理由 + 1 个备选。下表"catalog"列有脚本的直接从 `catalog/` 复制改；
写着"脚本"的还没有现成脚本，用 `Page` + 对应模板现写，写完补进 catalog。

## 1. 通用判断

| 数据形态 | 首选 | 别用 |
|---|---|---|
| 有序 X（时间、温度、PV、深度、压力）+ 连续 Y | 折线；实测点 + 拟合虚线 | 柱状 |
| 两个连续量看关系 | 交会图（散点）+ 拟合线 + R² | 折线（X 无序时） |
| 类别 × 1 个量，每组 n ≥ 10 | 箱线 + 散点叠加 | 只画均值柱 |
| 类别 × 1 个量，每组 n < 10 或单值 | 柱状 + 误差棒（图注写清 SD / SEM 和 n），或点图 | 3D 柱 |
| 构成（总量有意义） | 堆积柱 / 堆积面积 | 3D 饼 |
| 构成（只看占比、≤ 5 类） | 饼图可以用（油气能源类论文常见），但 > 5 类改横向柱 | 3D 饼 |
| 跨 3 个量级以上 | log 轴（`ogfig.cli inspect` 会提示） | 线性轴压扁 |
| 二维场（压力场、饱和度场、温度场） | 等值线 / 热图 + 色标（带单位） | rainbow / jet 色图 |
| 两个量纲不同、共享 X | 双 Y 轴（`DualY`），两条曲线颜色和轴对应；关系弱时拆上下面板共享 X | 无关变量硬凑双 Y |

## 2. 油气工程

| 图 | 坐标 / 画法要点 | catalog |
|---|---|---|
| 产量递减（Arps） | 半对数 Y，实测散点 + 拟合虚线，标 b、Di、R² | `production/decline_dashboard_2x2.py` (a) |
| 含水率 / GOR 随时间 | 线性，0–100 %，多井不同色 + 直接标井名 | 同上 (b) |
| 措施效果对比 | 柱 + 误差棒，类别轴用 `pg.categories` | 同上 (c)、`production/bar_line_side_by_side.py` |
| 试井 log-log 诊断 | 双对数，Δp 实线 + 导数虚线，标流动段（井储 / 径向流 / 边界） | 同上 (d)；模板 `og_loglog` |
| 产量 + 含水双 Y | 左柱右线，线上实心点 | `production/bar_line_dualy.py` |
| 产量构成 + 趋势 | 饼 + 折线并排 | `production/pie_line.py` |
| 岩心驱替：采收率 / 含水 / 注入压力 vs PV | 共享 X（PV），**三 Y 轴**或上下两面板；见水点竖虚线 | 脚本（三 Y 待补） |
| 相渗曲线 | Sw 0–1，krw / kro 两条，标 Swr、Sor 端点；可配分流曲线 | 脚本（`data.corey` / `fractional_flow`） |
| 毛管压力 / 压汞 | Pc 对数 Y vs 汞饱和度；孔径分布：log X + 柱 + 累计线（双 Y） | 脚本 |
| NMR T2 谱 | log X（0.01–10⁴ ms），饱和 / 离心前后对比，T2 截止值竖虚线 | 脚本；模板 `og_stack` 可叠谱 |
| 深度剖面（测井、温压） | **Y 轴反向**（深度向下），多道并排共享深度 | 脚本（反向轴待补） |
| 敏感性分析 | 龙卷风图（横向柱，按影响排序） | 脚本 |
| 正交 / 响应面 | 等值线 + 色标；3D 曲面只放补充材料 | 脚本 |

## 3. 油气化学

| 图 | 坐标 / 画法要点 | catalog |
|---|---|---|
| TG + DTG | 双 Y：TG 实线、DTG 同色虚线，温度 / 升温速率直接标在线旁 | `thermal/tga_dtg_dualy.py` |
| 多升温速率 TG | 错位叠放（瀑布），右端标速率 | `thermal/tga_waterfall.py` |
| XRD / Raman | 叠谱，Y 轴不显示刻度，特征峰标晶面 | `spectra/xrd_stack.py`；模板 `og_stack` |
| FTIR | 叠谱，**X 轴反向**（4000 → 400 cm⁻¹），官能团位置竖虚线 + 标注 | 脚本（反向轴待补） |
| 界面张力 vs 浓度 | log X，标 CMC 拐点 | 脚本 |
| 流变：黏度 vs 剪切速率 | 双对数，多温度 / 浓度不同色 | 模板 `og_loglog` |
| 吸附等温线 | 实测点 + Langmuir / Freundlich 拟合虚线，标拟合参数 | 脚本 |
| 碳数分布 / SARA 组分 | 柱状（C1–C40）；SARA 用堆积柱 | 脚本 |
| 分子模拟：RDF、MSD、密度分布 | 折线，多体系不同色；MSD 可配斜率拟合 | 脚本 |
| 动力学（KAS / FWO 活化能） | 线性拟合族：ln(β/T²) vs 1/T，每个转化率一条 | 脚本 |

## 5. 拆图信号

- 一个面板 > 5 条曲线；
- 两条曲线量纲不同又不共享 X；
- 一张图想说两件事（例如"递减规律"和"措施效果"）——拆成 (a)(b)，各说一件。
