# 样式规范（用户的硬性规范 + 配色用法）

**这一份是"我的风格"，优先级高于任何期刊默认或通用作图建议。** 数值都在 `ogfig/config.py` 的 `PREFS`，
改那里即可；本文件只解释规则和理由。

## 1. 硬性规范（每张图默认执行，不需要用户再说）

| # | 规范 | 落在哪 |
|---|---|---|
| 1 | 图里每一处文字：**西文 Times New Roman，中文宋体**。轴标题、刻度数字、图例、数据标签（饼图百分比、柱顶数值）、曲线标注、面板字母、题注，一个不漏 | `PREFS['font_latin'/'font_cjk']`；四类文字的属性见坑 #20、#25、#30、#31 |
| 2 | **字号 7–9 pt（成图实际尺寸）**：刻度数字 7、轴标题 8、图例 / 曲线标注 8、面板字母 9 粗体 | `PREFS['fs_tick'/'fs_title'/'fs_note'/'fs_letter']`。页面是真实毫米，导出不缩放，所以 PDF 里量出来就是这些值 |
| 3 | 有数据的边（左 / 下 / 右）**主刻度朝内**；无数据的上边框只留框线、不要刻度 | `tick_major='in'`，`frame_ticks=False` |
| 4 | **不要次刻度** | `minor_ticks=False` |
| 5 | 轴标题里的单位不重复：`DTG (%/℃)` 只出现一次 | 写标题时自查；列 long name 会被自动当标题（坑 #17） |
| 6 | 双 Y 轴用 Origin 自带 doubley（skill 里是 `og_doubley` 模板 / `ogfig.DualY`），右轴刻度同样朝内 | 坑 #15、#22、#23、#35 |
| 7 | 题注无边框，放面板空白角，不压曲线 | `pg.caption(i, text, where='tl')` |
| 8 | 线宽（成图 pt）：坐标轴 0.75、曲线 1.0、拟合线 1.2 虚线、主刻度长 3 | `PREFS['axis_thickness'/'line_width'/'tick_length']` |
| 9 | 多曲线 / 多序列图**默认加图例**：文字取列 long name、**无边框**、放坐标区四角中最空的那个角，四角都占满就加高页面上边、放右上角 | `pg.legend(i, where='auto')`；`PREFS['legend_pad_mm'/'legend_grow_mm']`；见本文第 5 节 |

## 2. 版式

| preset | 宽 × 高 (mm) | 用途 |
|---|---|---|
| `single` | 90 × 70 | 单栏单图（Fuel、JPSE、Energy、SPE J 单栏都在 85–90 mm） |
| `1.5` | 140 × 105 | 1.5 栏 |
| `double` | 180 × 130 | 双栏整幅，2×2 拼图 |

- 投稿前以目标期刊作者指南为准：Elsevier 单栏 90、1.5 栏 140、双栏 190 mm；ACS（Energy & Fuels）单栏 82.5（3.25 in）、双栏 178 mm（7 in）。需要时 `Page(size_mm=(190, 140))`。
- 边距与面板间距按 **mm** 给（`margin_mm=(14, 4, 6, 11)`，`gap_mm=(16, 15)`，双 Y 单图 `margin_dual_mm=(14, 14, 6, 11)`），换尺寸不会挤掉刻度数字和轴标题。
- 面板字母 `(a)(b)(c)` 统一放在面板框外左上角、同一 mm 偏移，**最后加**（版面定了再加）。
- 同一张拼图里：同一个变量在各面板同色、同线型；共享的轴用同样的范围和间隔。

## 3. 配色

八套色卡在 `config.py`，`PREFS['palette']` 切换，`style.C` 是当前那套。

| 色卡 | 特点 | 用来画 |
|---|---|---|
| `THERM`（默认） | 深色 5 色，冷→热 | 曲线、散点、温度 / 时间序列 |
| `OG` / `SPE` | 深色 6 色 | 曲线、柱状 |
| `OKABE` | 色盲安全 6 色 | 需要灰度 / 色盲可分时 |
| `BATT` / `HYDRO` / `PVSK` / `SAC` | **浅色**（马卡龙） | **只用于柱、面积、填充、阴影区间**；画细线在白底上看不清 |

规则：
- 同一面板 ≤ 5 条曲线，超过就拆面板；颜色不够时第 6 条用深灰 `style.GRAY`，不要循环回第 1 色。
- 实测点：实心符号；拟合 / 模拟：同色虚线（`dash=2`）。同一样品的 TG 实线、DTG 同色虚线。
- 柱状：同色系深浅区分，不要彩虹色；误差棒黑色。
- 对比用互补色对：`#2C6FAF` 蓝 vs `#C0504D` 红；`#B581B4` 紫 vs `#7FBDB0` 蓝绿。
- 行业惯例色（读者默认这样理解，尽量顺着）：产油绿、产气红、产水蓝；GR 绿、深电阻率红；砂岩黄、泥岩灰绿、碳酸盐岩蓝。
- 出图后看 `<name>_gray.png`（`export.report` 自动生成）：灰度下分不开就加线型 / 符号区分。

## 4. 文字写法

- 上下标用 LabTalk 转义（下面是 Python 普通字符串里的写法，`\\` 即一个反斜杠）：`q\\-(g)` → q_g，`10\\+(4) m\\+(3)/d` → 10⁴ m³/d。**`\\-g` 不带括号不会变下标**。
- 希腊字母直接写 Unicode（`θ`、`Δp`、`μm`），不要用 `\\g()`（坑 #34）。
- 单位：`k (10\\+(-3) μm\\+(2))`、`μ (mPa·s)`、`p (MPa)`、`RF (%)`、`PV`；中文刊用 10⁴ m³/d，英文刊用 10⁴ m³/d 或 MMscf/d，全文统一。
- 曲线标注优先直接写在曲线旁（`style.text_label`）；多曲线又没空白时用图例（第 5 节），图例一定去边框。

## 5. 图例

**默认加**：同一个面板 ≥ 2 条曲线 / 多序列柱，就调 `pg.legend(0)`。

| 规则 | 做法 |
|---|---|
| 文字来源 | **列 long name**——Origin 的 `\l(n) %(n)` 占位直接取它，不要手打条目。所以把单位和上下标写进列名：`ws.from_list(1, q, lname='产油量 q\\-(o) (10\\+(4) t)')` |
| 字体 | `legend.font=font(Times New Roman)`；中文无 TNR 字形时 Origin 自动回退宋体（实测 PDF 里中文变矢量轮廓，肉眼是宋体） |
| 字号 | `legend.fsize`（**不是** `.pt`，坑 #31），取 `fs_note`（normal 8 / bold 10） |
| 边框 | `legend.background=0` —— 图例的"边框"就是 background，设 0 即无边框 |
| 位置 | `where='auto'`：导探针图 → 四角各摆一个图例大小的框 → 取墨迹最少的；`score > legend_ink_max` 视为"被占" |
| 四角都占满 | 页面上边加高 `legend_grow_mm`（默认 20 mm），层整体下移，图例放**页面右上角**那条空白带；返回 `'tr-grow'` |
| 去重 | `'ls'` 是"线 + 点"两个 plot，不收敛会出现两条一模一样的条目；`Page.legend` 按 `_legend_idx` 只留线那条（坑 #42） |
| 不要图例的场景 | 单序列；类别轴已经写了名字的柱状图；**双 Y**（图例只认本层 plot，右层条目会丢）→ 改用曲线旁直接标注 |
| 残留图例 | 饼图 / 3D 图自带图例，用 `pg.drop_legends()` 或 `style.drop_legends(gl)` 删 |

## 6. 风格档（normal / bold）

同一个引擎出两套强度，`style.set_preset('bold')` 切换（**必须在 `Page(...)` 之前**，边距也跟着变）。

| 项 | `normal`（默认） | `bold`（明显版） |
|---|---|---|
| 字号 刻度 / 轴标题 / 图例 / 字母 | 7 / 8 / 8 / 9 | 9 / 10 / 10 / 11 |
| 坐标轴 / 边框 | 0.75 pt | 1.5 pt |
| 曲线 | 1.0 pt | 2.0 pt |
| 主刻度长 / 符号 | 3 / 4 | 4.5 / 6 |
| 页边距 mm（左右上下） | 14 / 4 / 6 / 11 | 17 / 4 / 8 / 13 |

用途：`normal` 投稿（受期刊 7–9 pt 约束）；`bold` 幻灯片、挂图、答辩、汇报——放大字和线，远看清楚。
`export.report` 的字号区间会跟着档位走（读 `PREFS` 的 min/max），所以 bold 不会误报。
